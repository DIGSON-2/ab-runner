# 🚀 AB Runner

**AB Runner** — это desktop-приложение на базе Electron для тестирования, автоматизации и массового выполнения HTTP-запросов к API. Инструмент позволяет объединять запросы в коллекции, использовать динамические данные (плейсхолдеры) из JSON-файлов и анализировать историю выполнения. Интерфейс вдохновлен Postman, но специально заточен под пакетный запуск (batch processing) и работу с наборами данных.

## ✨ Основные возможности

- **📁 Структурирование:** Организация коллекций по папкам с поддержкой Drag-and-Drop.
- **🔄 Пакетный запуск (Runner):** Выполнение цепочки запросов для каждого элемента из загруженного JSON-массива.
- **🧩 Плейсхолдеры:** Использование переменных вида `{id}` или `{user.name}` в URL, заголовках и теле запроса, которые автоматически заменяются на данные из файла.
- **📥 Импорт cURL:** Быстрое создание шагов из скопированных cURL-команд.
- **🎨 Генератор JSON-данных:** Встроенный инструмент для быстрого создания тестовых массивов данных.
- **📜 История запросов:** Логирование всех выполненных запросов (как одиночных, так и пакетных) с фильтрацией по коллекциям и детальным просмотром ответов.
- **🎨 Темы оформления:** 4 встроенные темы (Тёмная, Светлая, Красно-белая, Красно-чёрная) с адаптивной подсветкой синтаксиса JSON.
- **🔁 Автообновление:** Встроенный механизм проверки и установки обновлений через `electron-updater`.
- **💾 Локальное хранение:** Все коллекции и история сохраняются локально на вашем устройстве в системной папке `userData`.

## 📖 Руководство пользователя

### 1. Создание коллекций и шагов
- Нажмите **➕ Новая коллекция** в нижней части боковой панели или на пустом экране.
- Для организации коллекций можно создавать **папки** (кнопка 📁 в боковой панели).
- Для добавления запроса откройте коллекцию и нажмите **+ Добавить шаг**.
- Настройте шаг:
  - **Метод:** `GET`, `POST`, `PUT`, `PATCH`, `DELETE`.
  - **URL:** Адрес эндпоинта. Поддерживает плейсхолдеры (например, `https://api.example.com/users/{id}`).
  - **Headers:** Заголовки запроса в виде таблицы (как в Postman), с возможностью включения/отключения каждого заголовка чекбоксом.
  - **Authorization:** Токен авторизации (будет передан как заголовок `Authorization`).
  - **Body:** Тело запроса в формате JSON с подсветкой синтаксиса, автоформатированием и поддержкой комментариев `//` и `/* */`.

### 2. Использование плейсхолдеров
В URL и теле запроса вы можете использовать фигурные скобки для вставки данных:
- `{id}` — подставит значение поля `id` из текущего элемента данных.
- `{user.email}` — поддерживает вложенные объекты (через точку).

### 3. Подготовка данных (Файл данных)
Для пакетного запуска вам понадобится JSON-файл, содержащий **массив объектов**.
Вы можете создать его вручную или использовать встроенный **Генератор JSON**:
1. Нажмите кнопку **📝 JSON** на тулбаре.
2. Задайте имена полей (ключи) и перечислите значения через запятую.
   *Пример: Поле `id` со значениями `1, 2, 3` создаст массив из трех объектов.*
3. Длины всех списков должны совпадать.
4. Нажмите **💾 Сохранить как...** и выберите место для файла.

### 4. Запуск коллекции (Runner)
1. Выберите коллекцию в боковом меню.
2. Во вкладке **Раннер** нажмите **📂 Выберите файл** и загрузите подготовленный JSON-файл.
3. Укажите **Задержку (мс)** между итерациями (опционально, чтобы не превысить rate limits API).
4. Нажмите **▶ Запустить**.
5. Результаты будут отображаться в таблице в реальном времени. **Двойной клик** по строке откроет модальное окно с детальным ответом сервера, заголовками и телом запроса.

### 5. Одиночный запрос (Send)
Если вам нужно протестировать один шаг без запуска всей коллекции:
1. Нажмите зеленую кнопку **▶ Send** в карточке шага.
2. Введите тестовые данные (JSON) для замены плейсхолдеров.
3. Нажмите **▶ Отправить** (или `Ctrl+Enter`).

### 6. Импорт из cURL
1. Скопируйте cURL-команду из браузера (DevTools → Copy as cURL) или терминала.
2. В карточке шага нажмите **📋 cURL**.
3. Вставьте команду и нажмите "Импортировать". Приложение автоматически распарсит метод, URL, заголовки и тело запроса.

### 7. История запросов
- Перейдите на вкладку **История** в правой части экрана.
- Используйте выпадающий список для фильтрации по конкретной коллекции.
- **Двойной клик** по любой строке открывает детальный просмотр запроса и ответа.
- Кнопка **🗑 Очистить историю** удалит весь лог.

## 🌍 Окружения (Environments)
Окружения позволяют хранить глобальные переменные (например, `baseUrl`, `apiToken`), которые можно использовать в любых запросах.

1. **Создание/Импорт:** Нажмите кнопку **📥 Postman** и выберите файл окружения (Environment JSON), экспортированный из Postman. Либо создайте вручную через кнопку ⚙️ рядом с селектором.
2. **Использование:** В URL, заголовках или теле запроса используйте синтаксис `{{имя_переменной}}`.
   *Пример: `{{baseUrl}}/users/{id}` — `baseUrl` возьмется из окружения, а `{id}` — из файла данных Runner'а.*
3. **Переключение:** Используйте выпадающий список **No Environment** в боковой панели для быстрого переключения между Dev, Stage и Prod окружениями.

## 📥 Импорт из Postman
Приложение поддерживает нативный импорт данных из Postman:
1. В Postman выберите нужную Коллекцию или Окружение.
2. Нажмите **Export** и выберите формат **Collection v2.1** или **Environment v2.0.0** (JSON).
3. В AB Runner нажмите кнопку **📥 Postman** на тулбаре.
4. Выберите один или несколько JSON-файлов. Приложение автоматически определит тип файла:
   - **Коллекции** будут добавлены в ваше дерево с сохранением всех запросов, заголовков и тела.
   - **Окружения** появятся в списке доступных окружений.
   - Если в коллекции были заданы *Collection Variables*, они автоматически импортируются как отдельное окружение.

> **Приоритет переменных:** Если переменная с одинаковым именем есть и в файле данных Runner'а (`{id}`), и в активном Окружении (`{{id}}`), приоритет всегда отдается данным из Runner'а.
## ⌨️ Горячие клавиши

| :--------------------- | :--------------------------------------------------------- |
| `Ctrl/Cmd + S`         | Сохранить текущие изменения                                |
| `Ctrl/Cmd + N`         | Создать новую коллекцию                                    |
| `Ctrl/Cmd + Shift + F` | Перевести фокус в строку поиска по коллекциям              |

## 📂 Хранение данных
Все ваши данные хранятся локально в системной папке пользователя (`app.getPath('userData')`):
- `ab-runner-data.json` — ваши коллекции, папки и настройки.
- `ab-runner-history.json` — история выполненных запросов.

*Приложение автоматически создает резервные копии и импортирует данные из старых версий (`ab-runner-collections.json`) при первом запуске.*
