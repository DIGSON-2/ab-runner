# 🚀 AB Runner

**AB Runner** — настольное приложение для автоматизированной отправки HTTP-запросов с подстановкой данных из JSON-файлов. Создавайте коллекции запросов, импортируйте их из Postman и cURL, запускайте тесты с подстановкой значений и анализируйте результаты в удобном интерфейсе.

![AB Runner Screenshot](screenshot.png) *(если есть скриншот, добавьте ссылку)*

## ✨ Возможности

- **Коллекции и папки** — создавайте коллекции запросов, группируйте их в папки, перетаскивайте между папками, переименовывайте и удаляйте.
- **Запуск по данным (Runner)** — выберите JSON-файл с массивом объектов, и все шаги коллекции будут выполнены для каждого элемента с подстановкой значений в плейсхолдеры `{field}`.
- **Поддержка dot‑нотации** — используйте `{user.name}` для вложенных объектов.
- **Одиночные запросы (Send)** — отправьте тестовый запрос с ручным вводом данных и сразу увидите полный ответ.
- **Детальный просмотр ответа** — двойной клик по строке таблицы (или автоматически после одиночного запроса) открывает большое окно с URL, заголовками запроса/ответа, телом запроса/ответа и статусом. Есть кнопки для копирования.
- **Генератор JSON-данных** — быстро создайте массив объектов по заданным полям и спискам значений.
- **Импорт из cURL** — вставляете команду cURL, и приложение создаёт готовый шаг (метод, URL, заголовки, тело).
- **Импорт из Postman** — загрузите экспортированный JSON (коллекция v2.1, массив коллекций или полный дамп данных) и получите готовые коллекции. Окружения сохраняются в отдельные JSON-файлы с переменными.
- **Умный поиск** — ищет коллекции по названию, URL, методу и названиям шагов, используя **алгоритм триграмм (N‑грамм)**, поэтому находит даже при опечатках.
- **История запросов** — все успешные и неудачные запросы сохраняются в файл и не пропадают после перезапуска. Доступна фильтрация по коллекции.
- **Темы оформления** — 4 темы: тёмная, светлая, красно‑белая и красно‑чёрная. Переключаются в один клик.
- **Регулируемая боковая панель** — изменяйте ширину панели (от 200px до 40% экрана) или полностью скрывайте её, освобождая место для основного содержимого.
- **Стилизованные скроллбары** — тонкие и незаметные, подстраиваются под тему.
- **Безопасность** — используется `contextIsolation` и `preload` скрипт, нет прямого доступа к Node.js в рендерере.

## 📦 Установка и запуск

1. Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (версия 16 или выше).
2. Клонируйте репозиторий или скачайте исходники в папку `ab-runner`:
   ```bash
   git clone https://github.com/your-username/ab-runner.git
   cd ab-runner
Установите зависимости:

bash
npm install
Запустите приложение:

bash
npm start
Приложение откроется в окне 1300×850 пикселей.
Коллекции и история сохраняются в папку пользовательских данных Electron (%APPDATA%/ab-runner на Windows, ~/Library/Application Support/ab-runner на macOS, ~/.config/ab-runner на Linux).

🧩 Как пользоваться
1. Создание коллекции
Нажмите + в левой боковой панели.

Введите название (можно изменить двойным кликом в списке или в поле сверху).

2. Создание папок
Нажмите кнопку 📁 рядом с +.

Введите название папки.

Перетаскивайте коллекции в папки или используйте кнопку 📂 у каждой коллекции для перемещения.

Клик по папке сворачивает/разворачивает её содержимое.

3. Добавление шагов
Внутри коллекции нажмите + Добавить шаг.

Заполните поля шага:

Название шага (произвольное)

URL — может содержать плейсхолдеры {имя_поля}, например https://api.example.com/users/{id}

Метод — GET, POST, PUT, PATCH, DELETE

Authorization — токен (обычно Bearer ...)

Тело запроса — JSON или текст, с плейсхолдерами

Content-Type и Доп. заголовки (формат: Key: Value, Key2: Value2)

Все изменения сохраняются автоматически.

4. Импорт шагов из cURL
Нажмите 📋 Из cURL.

Вставьте команду cURL (поддерживаются все распространённые флаги: -X, -H, --header, -d, --data-raw, --location и т.д.).

Нажмите «Создать шаг» — новый шаг появится в коллекции.

5. Импорт коллекций из Postman
Нажмите 📥 Импорт Postman.

Выберите JSON‑файл, экспортированный из Postman:

одиночная коллекция (v2.1),

массив коллекций,

полный дамп данных (с полями collections и environments).

Будут созданы соответствующие коллекции в AB Runner.

Если в дампе есть окружения, программа предложит сохранить переменные каждого окружения в отдельный JSON‑файл (который затем можно использовать как файл данных для раннера).

6. Подготовка данных
Подготовьте JSON-файл с массивом объектов, например:

json
[
  { "id": "a1", "name": "Alice" },
  { "id": "b2", "name": "Bob" }
]
Или воспользуйтесь Генератором JSON (кнопка 📝 Создать JSON данных).

7. Запуск коллекции
Выберите файл данных (кнопка «Выберите файл»).

При необходимости установите задержку (мс).

Нажмите ▶ Запустить.

Результаты появятся в таблице: элемент данных, название шага и статус (✓ успех / ✗ ошибка).

8. Просмотр деталей ответа
Из таблицы: дважды кликните по строке — откроется окно с полной информацией (статус, URL, заголовки ответа, тело ответа).

Одиночный запрос: нажмите ▶ Send в любом шаге, введите тестовые данные (JSON), нажмите «Отправить». После отправки автоматически откроется окно с деталями, где дополнительно показаны заголовки и тело запроса.

9. История
Перейдите на вкладку История.

Просматривайте все выполненные запросы (из раннера и одиночные Send).

Фильтруйте по коллекции, обновляйте список, очищайте историю.

Двойной клик по строке открывает детальную информацию о запросе.

10. Боковая панель
Тяните за разделитель, чтобы изменить ширину панели (минимум 200px, максимум 40% ширины окна).

Нажмите ☰ Скрыть панель — панель исчезнет, останется только кнопка ☰ для возврата.

11. Смена темы
Внизу боковой панели нажмите 🔄 Сменить. Доступны: тёмная, светлая, красно‑белая, красно‑чёрная.

12. Умный поиск
Введите текст в поле поиска — коллекции будут отфильтрованы по названию, шагам, URL и методам, используя алгоритм триграмм (даже при опечатках).

Папки, в которых не осталось подходящих коллекций, автоматически скрываются.

🔧 Технические детали
HTTP-клиент: axios

Десктопный фреймворк: Electron

Безопасность: включена изоляция контекста, используется preload.js для защищённого IPC.

Хранение данных: коллекции и история сохраняются в JSON‑файлы в папке userData приложения.
